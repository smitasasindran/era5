# NN Visualized

This project is an interactive deep learning course.

## Architecture

- React + Vite
- Tailwind
- TensorFlow.js
- Plotly

## Rules

- Always reuse components.
- Never duplicate UI.
- Keep TensorFlow outside React.
- Use hooks/controllers for orchestration.
- Every chapter follows the same structure:
  Claim
  Overview
  Interactive Experiment
  Comparison
  What to Observe
  Why It Matters
  Key Takeaway
  Challenge Yourself

## Design

Activation Functions is the reference implementation.

Future chapters should match its appearance unless instructed otherwise.
